# Generateur-de-mot-de-passe-robuste
application cpp qui génère un mot de passe robuste entre 4 et 12 caractère

- installer le .exe
- lancé le .exe
- vous tombez sur editeur non verifier alors vous faite exécutez quand même ou plus d'information et éxécutez quand même
- suivez les instruction
- fin mot de passe généré
